Number Merge

Slide the tiles. When two tiles with the same number touch, they merge into one. Try to reach 2048!

How to play

  1. Slide all tiles up, down, left or right.
  2. Two tiles with the same number merge: 2 + 2 = 4, 4 + 4 = 8 …
  3. A new tile appears after every move.
  4. Reach the 2048 tile to win (you can keep going).
  5. The game ends when no moves are left. Use Undo once per move.
